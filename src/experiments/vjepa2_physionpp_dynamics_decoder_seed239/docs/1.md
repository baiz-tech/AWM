更新后的 object-level supervision 为：

```text
presence_logits       [B,8]
target_logits         [B,8]
object_type_logits    [B,8,K]
color_pred            [B,8,3]
```

不再包含：

```text
mass_pred
friction_pred
bounciness_pred
scale_pred
```

Physion++ 和 CLEVRER 的主要差别现在只在于：

```text
CLEVRER:
color / material / shape

Physion++:
target-object / object type / RGB color
```
