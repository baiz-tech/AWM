# 溯因式世界模型：论文大纲（溯因式状态建模范式）

## 0. 一句话定位

本文提出一种**溯因式状态建模范式**（abductive state modeling）：

> 世界模型不是单纯生成未来像素，而是从当前视觉证据中选择能够解释观测、预测后果、并对受控干预保持一致的潜在世界状态。

在视频任务中，这一范式由 AWM（Abductive World Model）实现，HASP（Hierarchical Abductive State Pyramid）负责把视觉证据组织成 Entity、Dynamic 和 Relation 三类状态。

因此论文的贡献不是“增加三个 decoder”，而是提出一个可检验的判据：

```text
可解释性 + 可预测性 + 干预一致性
       ↓
才构成可复用的世界状态
```

---

## 1. 摘要（建议版本）

现有视频基础模型能够从大规模视频中学习丰富的对象、运动和交互表征，但这些信息通常分散在高维视觉 token 中，模型难以说明当前观测对应的潜在状态是什么，也难以验证预测是否真正依赖这些状态。本文提出溯因式世界模型（Abductive World Model, AWM），将视频世界建模定义为一种溯因式状态推断问题：给定部分观测，模型寻找能够解释当前证据并预测未来结果的潜在状态；当输入证据发生受控改变时，该状态还应以与干预因素一致的方式变化。

AWM 以冻结的预训练视频编码器为感知基础，引入层级溯因状态金字塔（Hierarchical Abductive State Pyramid, HASP）。HASP 根据视频未来结果所需的条件依赖关系，将 patch 级观测依次组织为对象中心的 Entity state、描述状态演化的 Dynamic state 和刻画实体交互的 Relation state，并通过 residual 方式形成统一的世界状态接口。该结构对应一个可解释的状态分解：

$$
p(Y_{t+\Delta}|X_{1:t})
= \sum_{O,D,R} p(Y_{t+\Delta}|O,D,R) p(R|O,D) p(D|O,X_{1:t}) p(O|X_{1:t}).
$$

我们在 Physion++、CLEVRER 和 EPIC-KITCHENS-100 上验证这一范式，并分别测量状态的信息可解码性、预测充分性、干预选择性和跨组合迁移性。结果显示，Relation state 对接触和交互信息具有最强可解码性，Dynamic state 包含运动和事件进程信息，Entity state 保留对象级语义；状态置换和输入证据干预进一步检验这些信息是否参与最终预测。在 Physion++ 上，full-patch structured probe 获得约 72.19% OCP AUROC；在严格 EK100-only 设置下，验证集达到 69.05% Verb Top-1、47.59% Noun Top-1 和 43.12% Action Top-1。AWM 提供了一种不依赖像素级未来生成、但能够统一支持物理预测、事件推理和动作识别的可分析世界状态接口。

## 2. 引言：为什么需要溯因式状态建模

### 2.1 现有范式的不足

- 视觉基础模型的 token 具有信息，但不等于可复用的世界状态。
- 未来预测模型通常优化结果误差，却不要求中间状态能够解释结果。
- object-centric、temporal modeling 和 relation modeling 往往被作为独立模块，缺少统一的状态判据。
- 仅用 linear probe 证明信息存在，不能证明模型在预测路径中使用了该信息。

### 2.2 核心定义

令视频观测为 $X_{1:t}$，未来任务结果为 $Y_{t+\Delta}$，潜在世界状态为 $S_t$。本文要求 $S_t$ 同时满足：

1. **解释充分性**：$S_t$ 能预测观测中的任务相关因素；
2. **预测充分性**：$S_t$ 能预测未来结果；
3. **干预一致性**：改变因素 $c_k$ 时，主要改变与 $c_k$ 对应的状态及预测。

可定义一个概念性目标：

$$
\mathcal{L}_{state}
= \mathcal{L}_{explain}
+ \mathcal{L}_{predict}
+ \lambda \mathcal{L}_{intervene}
+ \beta \mathcal{R}_{complexity}.
$$

当前实现主要通过冻结状态、任务 probe、输入干预和状态 swap 对该目标进行后验验证；完整的候选状态生成和联合优化属于后续扩展。

### 2.3 可验证命题

- **命题 P1：状态可读出**：Entity、Dynamic、Relation 分别包含对象、变化和交互相关证据。
- **命题 P2：状态可预测**：完整状态比 raw encoder 更能支持未来结果和任务标签预测。
- **命题 P3：状态有功能**：置换或屏蔽对应状态会选择性损害相关任务。
- **命题 P4：状态可溯因**：给定部分效应，状态能够对潜在原因进行候选排序。
- **命题 P5：状态可迁移**：状态在未见组合或环境中的下降小于表面视觉基线。

### 2.4 贡献

1. 提出溯因式状态建模范式，并以解释—预测—干预一致性作为其可检验判据。
2. 给出由视频预测变量条件依赖关系诱导的 HASP 状态分解。
3. 提供从信息存在到功能使用、再到溯因和泛化的统一验证协议。
4. 在 Physion++、CLEVRER 和 EK100 上验证同一状态接口的跨任务复用性。

## 3. 理论视角：从预测分解到层级状态

### 3.1 状态分解的动机

假设未来结果由对象状态、对象变化和对象交互共同决定：

$$
Y_{t+\Delta}=f(O_t,D_t,R_t).
$$

则从观测到结果的推断可写为：

$$
p(Y|X)=\sum_{O,D,R}p(Y|O,D,R)p(R|O,D)p(D|O,X)p(O|X).
$$

这给出 HASP 的顺序：

```text
patch evidence -> object state O -> transition state D -> interaction state R -> outcome Y
```

该顺序不是按网络深度任意命名，而是对应从“谁/是什么”到“如何变化”再到“谁与谁发生作用”的条件依赖。

### 3.2 溯因状态评分

对于部分观测 $X_{1:t}$ 和候选解释 $h_i=(O_i,D_i,R_i)$，定义：

$$
s(h_i)=\log p(X_{1:t}|h_i)+\log p(Y|h_i)-\lambda\Omega(h_i).
$$

模型应优先选择既能解释当前证据、又能预测结果的候选状态：

$$
h^*=\arg\max_{h_i}s(h_i).
$$

当前第一版可用 candidate ranking、结果校准和遮挡前后排序变化验证这一思想；若未来加入 hypothesis tokens 或概率化 latent，才可进一步声称多假设后验推断。

### 3.3 与已有模型的区别

| 范式 | 主要目标 | 是否要求解释状态 | 是否验证干预选择性 |
|---|---|---:|---:|
| 纯视频分类 | 直接预测标签 | 否 | 否 |
| 未来 latent/像素预测 | 最小化未来误差 | 不一定 | 通常不 |
| Object-centric 表征 | 提取对象因素 | 部分 | 通常不 |
| AWM | 解释当前证据并预测未来 | 是 | 是 |

## 4. 方法：AWM/HASP 实现

### 4.1 输入与冻结感知

- 输入：`[B, T, H, W, 3]`。
- V-JEPA 2 Encoder 输出 `Z_patch`。
- Predictor（启用时）由 context latent 预测 future latent，不输入真实未来帧。

### 4.2 三类结构化状态

| 状态 | 作用 | 当前主要证据 |
|---|---|---|
| Entity | 对象中心语义、属性和局部状态 | noun、对象属性、slot 对齐 |
| Dynamic | 时间变化、运动和事件进程 | verb、速度、TTC、时间干预 |
| Relation | 对象对相对状态和交互 | contact、contact-rate、collision |

状态沿层级构造：

```text
Z_patch -> Z_entity -> Z_dynamic -> Z_relation
                         \            /
                          residual refined tokens
```

HASP 不是三个并列分类头；它是对同一观测证据进行逐步状态化的推断路径。

### 4.3 任务读出与权重边界

- Physion++：OCP/contact/TTC readout。
- CLEVRER：QA、事件链和反事实 readout。
- EK100：verb、noun、action heads。
- Encoder/HASP 主实验冻结；分类头按数据集独立训练。
- 各数据集不互相使用标注、probe checkpoint 或 validation 标签。

## 5. 实验设计：验证五个命题

### 5.1 P1：信息存在

对 `Z_patch`、Entity、Dynamic、Relation、refined tokens 使用相同容量 probe，预测对象、运动和关系因素，绘制 Layer × Factor 矩阵。

证明：层级状态确实包含相应信息，而非仅由名称赋予解释。

当前结论：Relation 对 contact/contact-rate 为强证据；Dynamic 对 motion/event 为中等证据；Entity 需要补充对象属性和 slot 对齐实验。

### 5.2 P2：预测充分

比较 raw encoder、单层状态、两层组合、完整 HASP，并匹配 readout 参数量。

证明：层级状态是否比表面 token 更适合作为未来预测和任务预测接口。

### 5.3 P3：功能使用与干预一致性

对 Entity/Dynamic/Relation 做置零、batch shuffle、跨样本 swap、保持均值方差的替换；对输入做局部对象 mask、时间逆序、relation edge rewiring。

报告目标任务下降、非目标任务下降和选择性比值：

$$
\text{selectivity}=
\frac{\Delta \text{target}}{\operatorname{mean}(\Delta \text{non-target})}.
$$

证明：状态不仅可解码，而且位于模型预测路径中。

### 5.4 P4：操作性溯因

隐藏初始施力、碰撞前状态、初始位置或运动方向，只保留后续效应；要求模型对候选原因进行排序。

指标：Cause Top-1/Top-5、candidate ranking accuracy、状态 MAE、Brier/ECE，以及随观测证据增加的 ranking 曲线。

证明：模型能够从可见效应恢复未直接观测的潜在状态。

### 5.5 P5：组合与环境迁移

测试未见 verb-noun 组合、未见对象组合、留一物理场景、participant/kitchen OOD。

证明：状态学习的是可组合因素，而不是训练集中的表面共现。

## 6. 三个数据集的验证重点

### 6.1 Physion++

- Entity：slot-object matching、属性、轨迹和身份保持。
- Dynamic：速度、加速度、TTC、时间方向。
- Relation：contact graph、first-contact、edge rewiring、OCP。
- 核心论点：AWM 能根据对象关系和运动状态预测物理结果。

当前可谨慎表述：Relation state 已有最强的关系证据；Dynamic 含运动信息但尚未完全专门化；Entity 仍需更严格的对象对齐证据。

## 7. 当前已有实验结果与阶段性结论

本节只记录目前已经完成并保存到 `analyze/results` 的实验，不把规划实验的预期结果写成事实。具体指标文件见：

- Physion++ 原生因素解码：`analyze/results/full/metrics/physion_slot_time_matrix.json`、`physion_pair_relation_matrix.json`
- Physion++ 输入证据消融：`analyze/results/full/metrics/physion_input_ablation_ratio50.json`
- Physion++ Predictor regeneration：`analyze/results/full/metrics/physion_predictor_regen_ablation.json`
- Physion++ Relation 实例干预：`analyze/results/full/metrics/physion_relation_instance_ablation.json`
- EK100 层级解码：`analyze/results/full/metrics/ek100_verb_layer_matrix.json`、`ek100_noun_layer_matrix.json`

### 7.1 主任务结果

| 数据集/设置 | 指标 | 当前结果 | 解释 |
|---|---:|---:|---|
| Physion++ full-patch structured probe | Test OCP AUROC | **72.19% ± 0.11%** | 当前 Physion++ 主结果 |
| Physion++ full-patch structured probe | Test balanced accuracy | **66.17% ± 0.42%** | 多 seed 汇总 |
| Physion++ full-patch structured probe | Test accuracy | **65.63% ± 0.79%** | 多 seed 汇总 |
| CLEVRER / AWM-HASP | 多物体行为预测一致性 | **0.42 → 0.49** | 相对 baseline 提升 0.07，约 16.7% |
| EK100 V23 EK100-only | Verb Top-1 | **69.05%** | 仅使用 EK100 训练，不复用 Physion++ readout |
| EK100 V23 EK100-only | Noun Top-1 | **47.59%** | 训练词表内 closed-set 评估 |
| EK100 V23 EK100-only | Action Top-1 | **43.12%** | verb-noun 组合预测 |

注：72.19% ± 0.11% 是当前主实验报告的 Test AUROC；后文消融表中的 0.7907 是 800 条 validation clip 上、特定冻结 readout/干预协议下的 OCP AUROC，二者不是同一评测 split 或同一统计口径，不能直接互换。

EK100 的 Top-5 结果明显高于 Top-1，说明表征通常已经保留了正确语义候选，但最终排序仍受到细粒度对象、长尾类别和 verb-noun 共现偏差影响。该现象支持后续做 calibration、长尾分桶和 Top-5 词表分析，而不能简单解释为“模型已经完全理解动作”。

### 7.2 Physion++ 原生因素解码

这些实验冻结 Encoder、Predictor 和 HASP，仅训练离线 readout，直接预测原生物理因素。

| HASP 层级 | 已解码因素 | 当前最强结果 | 阶段性结论 |
|---|---|---:|---|
| Entity | object presence、object extent | presence AUROC **0.9611**；extent $R^2$ **0.5588** | 包含对象存在性和几何尺度信息 |
| Dynamic | speed、3D velocity、future position | speed $R^2$ **0.7314**；velocity $R^2$ **0.3808** | 包含时间分辨的运动信息，但并非完全专门化 |
| Relation | pair distance、contact、TTC | contact AUROC **0.9854**；TTC $R^2$ **0.5483** | 对象对交互信息的证据最强 |

当前最稳妥的解释是：Relation 的关系信息证据最强，Dynamic 的运动信息证据为中等到较强，Entity 的对象存在性和尺度证据明确；不能据此声称三个层级信息完全正交，也不能声称每个 slot 唯一对应一个真实因果实体。

#### 7.2.1 完整缓存复现实验（8000 train / 800 validation）

补充的 slot/time-resolved probe 和 pair-level probe 在完整缓存上复现了上述结论：Entity slot presence AUROC 为 **0.9634**，Entity extent $R^2$ 为 **0.5316**；Dynamic time feature 对 speed 的 $R^2$ 为 **0.7198**，对 velocity 的 $R^2$ 为 **0.3805**；Relation pair token 对 distance 的 $R^2$ 为 **0.5425**，对 contact 的 AUROC 为 **0.9847**，对 TTC 的 $R^2$ 为 **0.5542**。Pair-time feature 对 distance 的 $R^2$ 为 **0.5815**，对 contact 的 AUROC 为 **0.9789**。

这些结果比场景级 pooled probe 更直接，因为监督目标分别在 Entity/slot、Dynamic/time 和 Relation/pair 的原生粒度上定义。它们支持“各层级包含对应因素证据”的信息存在性 claim，但仍不支持完全解耦或真实因果实体对齐的强 claim。

### 7.3 EK100 层级可解码结果

冻结 EK100 V23 `readout.world`，使用等容量离线 probe：

| 任务 | Entity | Dynamic | Relation | 最强单层 |
|---|---:|---:|---:|---|
| Verb accuracy | 50.43% | **56.98%** | 30.99% | Dynamic |
| Noun accuracy | 31.61% | **33.03%** | 16.73% | Dynamic（略高于 Entity） |

该矩阵说明 Dynamic state 在当前实现中对动作标签最有读出性，但 noun 并未表现出理想的 Entity 专门化。因而 EK100 结果支持“层级状态携带互补动作线索”，暂时不足以支持“Entity 专门负责 noun、Dynamic 专门负责 verb”的强解耦表述。

### 7.4 输入证据干预与 Predictor regeneration

在 Physion++ validation 上，干预发生在 patch latent evidence，Encoder、Predictor、HASP 和 OCP readout 均冻结。

| 条件 | Entity extent MAE | Dynamic speed MAE | Contact AUROC | TTC MAE | OCP AUROC |
|---|---:|---:|---:|---:|---:|
| Cached baseline | 0.0292 | 0.0670 | 0.9837 | 0.1262 | 0.7907 |
| 50% object-guided mask | 0.0328 | 0.0739 | 0.9808 | 0.1307 | 0.7150 |
| 50% random mask | 0.0304 | 0.0692 | 0.9837 | 0.1278 | 0.7757 |
| Temporal static | 0.0580 | 0.1120 | 0.9485 | 0.2665 | 0.5646 |

仅遮挡 context 并由冻结 Predictor 重新生成 future latent 后，结果仍保持同样趋势：object mask + regeneration 的 OCP AUROC 为 0.7295，temporal static + regeneration 为 0.6392，而 regenerated baseline 为 0.7907。由此可以支持：对象和时间证据会沿 `context → Predictor → future → HASP` 路径影响结构化状态和物理预测。

### 7.5 Relation 实例级干预

使用真实 instance segmentation 对 contact pair 和 non-contact pair 做配对遮挡。contact-pair mask 后，pair contact AUROC 为 0.9488、TTC MAE 为 0.1376；non-contact-pair mask 后分别为 0.9518 和 0.1348。contact pair 对 relation 原生指标的退化略强，支持 Relation 对交互对象证据存在功能依赖。

在本轮完整复现实验中，Relation 实例干预共包含 372 个有效配对样本。相对于 baseline（contact AUROC **0.9633**、relation TTC MAE **0.1306**），contact-pair mask 使 contact AUROC 下降 **0.0145**、TTC MAE 上升 **0.0071**；non-contact-pair mask 使 contact AUROC 下降 **0.0115**、TTC MAE 上升 **0.0043**。同时，Entity presence AUROC 在 contact-pair mask 下下降 **0.0067**，而 OCP AUROC 分别下降 **0.0477** 和 **0.0820**。

但 OCP 在 non-contact pair mask 下下降更多，因此 OCP 不能作为 Relation 专门性的唯一指标；Relation 结论应以 contact、distance 和 TTC 等 pair-level 原生指标为主。

该结果支持 Relation 对交互对象证据存在功能依赖，但选择性并不完美：非接触 pair 的遮挡对 OCP 影响反而更大，说明 OCP 仍会受到一般视觉证据损失影响。因此这里的结论应限定为“pair-level relation 指标呈现相对选择性”，而不是“Relation 已被因果隔离”。

### 7.6 当前阶段性结论

目前已形成的证据链为：

```text
原生因素可解码
  → 对应输入证据被移除后性能退化
  → Predictor regeneration 保持退化传播
  → Relation 的真实实例干预呈现 pair-level 选择性
```

因此当前可以写：HASP 的三个状态均包含与其设计目标相关的可读信息，并且对象、时间和关系证据对物理预测具有可观测的功能贡献。当前仍不能写：三个状态已经完全解耦、模型恢复了真实因果机制，或已经完成多假设后验推断。

本轮新增的完整缓存离线分析将信息存在性的证据具体化为：

```text
slot-level Entity presence/extent
  + time-level Dynamic speed/velocity
  + pair-level Relation distance/contact/TTC
  → 各状态在其原生粒度上具有可读信息
```

对应的可复现实验文件为 `analyze/results/full/metrics/physion_slot_time_matrix.json`、`physion_pair_relation_matrix.json` 和 `physion_native_factor_matrix.json`。

## 8. 规划要做的实验

以下实验按“先补强现有 claim，再建立溯因范式证据，最后验证泛化”的顺序排列。

### 8.1 优先级 P0：补齐当前最薄弱的证据

1. **Entity 对象专门化**：在 Physion++ 和 CLEVRER 做 slot-object Hungarian matching、属性解码、轨迹 ADE/FDE、遮挡后 identity consistency；在 EK100 做 noun 长尾分桶和 object evidence mask。
   - 证明 Entity 不仅能判断对象存在，还保留对象身份、属性和局部语义。
2. **Dynamic 选择性**：对 Physion++ 做速度/加速度/TTC 解码，对 EK100 做逆序、随机序、变速、重复帧和前缀观察。
   - 证明 Dynamic 对状态变化和时间方向敏感，而不是只编码场景语义。
3. **Relation 选择性**：继续使用真实 instance mask，对 contact pair、non-contact pair 和随机 pair 做严格配对干预，并重新生成 future latent。
   - 证明 Relation 的退化来自交互对象证据，而不是一般信息损失。
4. **公平归因矩阵**：完成 E0–E4 对照并匹配 head 参数量。
   - 证明提升来自 HASP/共享状态，而不是第二次 world extraction 或额外参数。

### 8.2 优先级 P1：把“溯因”从叙事变成可测量机制

1. **候选原因排序**：在 Physion++ 隐藏初始施力、速度、方向或碰撞前帧，构造多个候选 $(O,D,R)$ 状态，计算 candidate score。
   - 指标：Cause Top-1/Top-5、MRR、Brier、ECE、随观测比例增加的 ranking 曲线。
   - 证明：模型能从可见效应中选择最能解释并预测结果的潜在状态。
2. **CLEVRER 模拟器反事实**：移除对象、改变初速度/位置/碰撞参数，比较真实结果变化与预测变化。
   - 指标：counterfactual accuracy、$\Delta$ outcome MAE、effect ranking Spearman、unaffected-object consistency。
   - 证明：状态推断对已知干预具有机制一致性。
3. **状态充分性测试**：给定相同的 Entity/Dynamic/Relation 状态，替换原始背景或外观，测试未来预测是否保持。
   - 证明状态是否真正压缩了任务相关世界因素，而不是依赖表面纹理。

### 8.3 优先级 P1：跨数据集和组合泛化

1. Physion++ leave-one-scene-out 与 low-shot 适配。
2. CLEVRER 未见颜色×形状、材质×运动、关系链组合。
3. EK100 未见 verb-noun 组合、participant OOD、kitchen OOD。
4. 报告 IID/OOD gap、calibration gap、mean-class Recall@5 和长尾类别性能。

证明：HASP 学到的是可组合、可迁移的状态因素，而不是训练集中的动作或场景共现。

### 8.4 优先级 P2：范式级增强

1. 引入 hypothesis tokens 或 mixture-of-states，使模型显式维护多个候选解释。
2. 联合优化 explain/predict/intervene 三类损失，并加入状态复杂度正则。
3. 与普通 temporal Transformer、object-centric baseline、predictive latent baseline 做同参数量比较。
4. 做 representation CKA/RSA 和 feature drift，验证 residual 是否保留 V-JEPA 原始语义。

这些实验用于把当前的“后验分析型溯因”升级为“模型内部显式候选状态推断”，但不应在尚未实现前写入已完成贡献。

### 8.5 计划实验的统一报告格式

每个实验都应同时报告四项：

| 报告项 | 内容 |
|---|---|
| 任务性能 | Top-1/Top-5、AUROC、balanced accuracy、MAE 或 QA accuracy |
| 状态证据 | 对应层级的 native factor probe 或表示变化 |
| 选择性 | 目标因素下降与非目标因素下降之比 |
| 结论边界 | 能支持什么、不能支持什么 |

## 9. 公平对照和归因边界

EK100 必须拆解当前代码中的两次 world-state 提取：

```text
E0 raw encoder -> linear head
E1 raw encoder -> readout.world
E2 shared.world -> simple head
E3 shared.world -> frozen readout.world
E4 完整 residual HASP
```

所有对照匹配 readout 参数量，并明确：哪些权重复用、哪些权重冻结、哪些 head 在目标数据集训练。否则无法判断提升来自 HASP、第二个 world extractor，还是额外参数。

## 11. 最终结论与边界

若实验成立，论文最终应主张：

> AWM 将世界模型定义为一种溯因式状态推断过程。HASP 是这一范式在视频中的结构化实现：它把观测证据逐层组织为实体、动态和关系状态，并要求这些状态同时具备可解码性、预测充分性和干预一致性。跨 Physion++、CLEVRER 和 EK100 的实验表明，该状态接口能够支持物理预测、事件推理和动作识别，并在一定程度上恢复未直接观测的潜在原因。

不要直接声称：

- 发现了真实因果机制；
- 学习了环境不变的物理定律；
- 每个 slot 都对应唯一真实因果实体；
- 已实现完整的后验多假设推断；
- 已获得通用跨环境因果泛化。

论文最重要的科学问题最终归结为：

```text
什么是可解释的世界状态？
它能否预测未来？
模型是否真的使用它？
干预时它是否按机制选择性变化？
它能否从结果恢复潜在原因并迁移到新组合？
```
